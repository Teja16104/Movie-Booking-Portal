# Movie Booking Portal

A console-based Movie Booking Portal using Java nested if-else statements.

## Features
- Enter customer details
- Select a movie
- Check A-rated movie age restrictions
- Choose theatre type
- Select seat category
- Choose payment method
- Display booking confirmation and total amount

## Technologies Used
- Java
- Scanner class
- Conditional statements
- Nested if-else statements

## How to Run
1. Download `MovieBookingPortal.java`.
2. Open it in Eclipse or any Java IDE.
3. Run the program.
4. Enter customer details and select movie options.
5. Choose theatre, seat and payment method.
6. View the booking confirmation.
